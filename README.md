# Lingua 语言学习平台 · 0.6.0

## 仓库结构

- `app/`：Android 应用（Jetpack Compose UI、ViewModel、Room 数据层、TTS 发音服务）
- `core/`：纯 Kotlin 业务逻辑（模型、语言模块、复习调度、答案评估、AIService 契约）
- `teacher_backend/`：教学网关后端原型（Python 标准库 + SQLite，未部署）
- `supabase/`：云端词库导入 / 导出 / 验证脚本
- `outputs/`：验收记录、云端迁移记录与发布产物（APK 通过 GitHub Releases 发布，不入库）
- `build.ps1` / `install.ps1`：构建与真机安装脚本

## 本版功能

- 统一 Material 3 设计系统：颜色、字体、圆角、间距、卡片与主按钮；支持浅色和深色主题。
- 首页今日目标、学习/复习入口、完成进度、连续天数、学习时间与最近学习情况。
- 主动回忆：先隐藏答案，查看后选择会 / 模糊 / 不会，结果进入独立复习调度器。
- 韩→中、中→韩、例句、随机测试、错题强化、今日复习、单词和例句听力。
- 单词详情、多例句、关键词、词性、搭配、相似词、反义词、收藏、加入复习、标记掌握。
- 月度打卡日历与每日详情；每日记录独立保存在 Room，不依赖界面临时计算。
- 累计、每周和最近七天统计。
- Android TextToSpeech 单词/例句发音，支持语言选择、重复播放、错误状态和资源释放。

## 架构

- core：纯 Kotlin 模型、LanguageModule / LanguageRegistry、ReviewScheduler、AnswerEvaluator、打卡分析及 AIService 契约。
- app/data：Room、非破坏性数据库迁移、Repository、独立例句表、每日记录表、JSON 内容适配器及 DataStore。
- app/ui：Compose、Navigation、ViewModel、共享 Design System。
- app/speech：PronunciationService 接口与 Android TTS 实现。UI 不直接依赖 TextToSpeech。
- assets/content：词库与例句分别存储，稳定 ID 关联；一个词可有多个例句。

Room 从版本 1 升级到 2 时保留学习历史并迁移旧例句；旧词表的例句字段仅为迁移兼容保留。当天首次练习固定目标，按不同单词数计算完成率，重复刷同一个词不会完成整个目标。✓ 表示完成，● 表示学习过。

## 构建与安装

本机工具位于 .tools，未修改系统 PATH。在项目目录 PowerShell 执行：

```powershell
./build.ps1
./install.ps1
```

安装脚本要求已授权的 Android 手机。标准环境使用 Android Studio、JDK 17、SDK 35 和 Gradle Wrapper。调试 APK 位于 app/build/outputs/apk/debug/app-debug.apk；正式发布需要自有签名。

发布版 APK 与验收记录通过 GitHub Releases 提供，请从 Releases 页面下载，仓库本身不保留安装包。

如果手机没有对应语言语音包，请在系统文字转语音设置中下载韩语语音。可用语音音色、离线能力与质量取决于手机安装的 TTS 引擎；本版不下载在线语音、不连接付费 API。

## 规则及边界

会：1 → 3 → 7 → 14 → 30 天；模糊退阶，最低 10 分钟；不会 1 分钟后复习。错题优先。翻译采用规范化标准答案 / 别名匹配和关键词提示，不能可靠判断所有同义表达、助词语法或自然程度；未来可替换 AnswerEvaluator 接入 AI。听力使用本地 TTS，不包含语音识别或跟读评分。

每日学习时间是已提交练习的作答时间，单题最多计 30 分钟。打卡连续天数以完成目标为准；学习连续天数以有练习记录为准。

扩展语言时注册新的 LanguageModule，提供词库、例句、语言标记与相关 provider，共享学习、数据库、统计和调度。PronunciationService 可替换为在线语音服务，AIService 暂未接入。CSV 导入 UI、私人账号同步、年度热力图、完整课程编辑器尚未实现。公开词库手动下载已实现，不上传学习记录。

不要把 API Key 放入 Android 客户端或 Git；未来付费 AI 调用应通过服务端代理。真实设备验证范围见 TESTING.md。
